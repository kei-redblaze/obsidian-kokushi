# 問題セット作成ガイド

[KokushiのREADME](../README.md)に戻る

## ファイルの配置

1問を1つのMarkdownファイルにします。`01_Questions/` 直下のフォルダー名が出典になり、ファイル名から拡張子を除いた部分が問題番号になります。同じ出典内では、サブフォルダーに分けても問題番号は一意にしてください。別の出典では同じ番号を使えます。

```text
<Vault>/
└── 01_Questions/
    └── 模擬試験A/
        ├── 001.md
        ├── 002.md
        └── images/
            └── case-01.png
```

画像は問題ファイルからの相対パスで参照します。上の例で `001.md` と `002.md` から同じ画像を使う場合は、両方に `![症例の画像](./images/case-01.png)` と書きます。ZIPで配布する場合は出典フォルダーをまとめ、受け取った人は展開した出典フォルダーを `01_Questions/` の直下に置きます。

## 単一選択

```markdown
## Question

心電図の記録に用いる機器はどれか。1つ選べ。

## Options

a. 心電計
b. 肺活量計
c. 眼圧計

## Answer

a. 心電計
```

別々の選択肢をそれぞれ1つの正答として認める場合は、正答行を空行で区切ります。たとえば `a. …` の後に空行を入れて `c. …` を書くと、`a` のみと `c` のみが正答です。

## 複数選択と「すべて選べ」

```markdown
## Question

体液バランスを把握するために記録する項目を2つ選べ。

## Options

a. 経口摂取量
b. 尿量
c. 利き手

## Answer

a. 経口摂取量
b. 尿量
```

同じ組み合わせは空行なしで並べます。別の組み合わせを認める場合は空行を挟みます。「すべて選べ」で `a` 単独と `a`・`b` の組み合わせを両方認める場合、`## Answer` は次のようになります。

```markdown
## Answer

a. 選択肢A

a. 選択肢A
b. 選択肢B
```

候補ごとに選択数が異なるときは、画面上で選択数を固定しません。採点は選択順を問わず、候補のいずれかとの完全一致で行います。

## 数値入力

```markdown
## Question

答えが12となった。3桁の半角数字で入力せよ。

## Answer

012
```

`## Options` を省略します。複数の値を正答とする場合は、半角数字だけの行を空行で区切ります。`012` と `12` は別の解答です。

## 採点除外と注記

```markdown
## Question

症例の所見に対応するものを選べ。

## Options

a. 所見A
b. 所見B

## Answer

採点除外

## Annotation

出典に公式解答の記載がなく、正答を確定できないため採点除外とした。
```

`## Answer` の本文が空でも採点除外になります。AIで作成する場合は、意図的に除外したことが分かるように `採点除外` と明記してください。選択肢があれば選択数を固定しないチェックボックス、選択肢のセクションがなければ数値入力欄を表示します。

`## Annotation` は任意です。採点後に「注記」として表示します。公式解答の有無、暫定解答の根拠、複数の見解がある場合の補足、本試験での除外理由などを記述できます。「本試験では誤答時のみ採点除外」のような注記を書いた場合も、Kokushiでは `## Answer` の記述に従って採点します。

## 独立して出題できる連問

**小問ごとに1ファイル**にし、どの小問も単独で出題される前提で作成します。各ファイルの `## Question` に、その小問に必要な共通症例文、検査所見、画像リンクを入れます。絞り込みやランダム出題によって、小問は離れて出題されることがあります。

以下の2問は同じ症例と画像を使う例です。どちらにも、出題に必要な症例文と画像リンクがあります。

### `001.md`

```markdown
## Question

70歳の男性。立位でふらつきを認める。臥位の血圧は130/80 mmHg、
立位3分後の血圧は105/65 mmHgであった。測定記録を示す。
収縮期血圧は立位で何mmHg低下したか。

![血圧の測定記録](./images/case-01.png)

## Answer

25
```

### `002.md`

```markdown
## Question

70歳の男性。立位でふらつきを認める。臥位の血圧は130/80 mmHg、
立位3分後の血圧は105/65 mmHgであった。測定記録を示す。
拡張期血圧は立位で何mmHg低下したか。

![血圧の測定記録](./images/case-01.png)

## Answer

15
```

## 順次出題する連問

CBTの4連問のように、症例情報を段階的に提示する問題は**1セットにつき1つのMarkdown**にまとめます。出典元の番号を `## 小問 Q37` のように見出しへ記述し、小問内の見出しは `### Question`、`### Options`、`### Answer`、`### Annotation` とします。最初から提示する情報は任意の `## 共通症例` に置き、途中で提示する情報は該当小問の本文に記述します。以下は2小問の記述例です。

```markdown
## 共通症例

診察室で立位の血圧を測定した。

## 小問 Q37

### Question

臥位での収縮期血圧は130 mmHg、立位で110 mmHgであった。
何mmHg低下したか。半角数字で入力せよ。

### Answer

20

## 小問 Q38

### Question

臥位での拡張期血圧は80 mmHg、立位で65 mmHgであった。
何mmHg低下したか。半角数字で入力せよ。

### Answer

15
```

履歴やメモには出典元の小問番号を使います。先頭ゼロは保持されます。同じ出典内では単独問題のファイル名と連問の小問番号を通して番号を一意にしてください。

ランダム出題でも、小問はファイルに書いた順に表示します。先に進むと確定済みの解答は変更できません。最後の小問を確定した後に、連問全体を採点して小問ごとの結果を表示します。途中で出題範囲の選択に戻り、未完了の演習から続けることもできます。

評価の条件に合う小問が1問でもあれば、連問全体が出題候補になります。出題数は小問単位で数え、枠に収まらない連問は見送ります。

## 配布前の確認

- 同じ出典内の問題番号が重複していないか確認します。
- `## Question` と `## Answer` の綴りを確認します。選択式には `## Options` が必要です。
- 正答の記号が選択肢に存在し、同じ候補内では重複していないか確認します。AIで作成した場合は、候補を区切る空行と問題文の指定が一致するかも確認します。
- 相対パスと画像のファイル名が一致し、画像が同梱されているか確認します。
- 連問の各小問を個別に開き、症例・検査所見・画像がそろっているか確認します。
- **設定 → Kokushi → 問題セットをチェック** で、書式と画像パスを確認します。続いて演習画面で問題の表示と採点を確認します。
